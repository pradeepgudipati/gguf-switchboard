# GGUF Switchboard brand assets

- `gguf-switchboard-logo.svg`: horizontal logo for light backgrounds.
- `gguf-switchboard-logo-on-dark.svg`: horizontal logo with a pale wordmark for dark backgrounds.
- `gguf-switchboard-mark.svg`: standalone product mark with a transparent canvas.
- `gguf-switchboard-logo.png`: transparent 1280 × 320 raster lockup.
- `gguf-switchboard-logo-on-dark.png`: transparent 1280 × 320 raster lockup for dark backgrounds.
- `gguf-switchboard-mark.png`: transparent 1024 × 1024 raster master.
- `favicon-16.png`, `favicon-32.png`, and `favicon-48.png`: browser favicon sizes.
- `apple-touch-icon.png`: 180 × 180 Apple touch icon.
- `icon-192.png` and `icon-512.png`: application/PWA icon sizes.
- `favicon.ico`: 48 px browser favicon for legacy consumers.

The icon is designed for both dark and light surfaces. Preserve transparent padding and do not add outbound wires, extra text, or a containing square.
