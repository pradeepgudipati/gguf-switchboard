# gguf-switchboard v0.1.8

**A clearer, easier path from discovery to a working local-model endpoint.** This release brands the API consoles, reorganizes the documentation around real setup and integration workflows, improves community contribution paths, and makes deployment updates safer.

## What's new

### Product and API experience

- Added consistent gguf-switchboard branding, reliably embedded logo assets, favicons, and navigation to Swagger UI and the Conformance Console.
- Refined the project positioning around one OpenAI-compatible endpoint for GGUF through llama.cpp and SafeTensors through vLLM.
- Added `ggs version`, `ggs --version`, and `ggs -V`, plus reorganized CLI help with copyable examples.

### Documentation and integrations

- Reorganized documentation into focused getting-started, model, runtime, deployment, API, architecture, and troubleshooting guides.
- Added setup guides for OpenCode, Cursor, Cline, Continue, and the OpenAI SDK.
- Added `llms.txt` and `llms-full.txt` to make project capabilities and documentation easier for AI assistants to discover.
- Added current Conformance Console screenshots and streamlined the README into a concise project landing page.

### Deployment reliability

- `deploy.sh` now merges stray `models.toml` files into the canonical deployed registry during upgrades.
- No-change pulls now skip unnecessary `ggs` binary installation and service restarts.
- Removed the unsupported Docker deployment files so the repository reflects the maintained Linux/systemd, macOS, and WSL2 paths.

### Community workflows

- Added a complete contribution guide.
- Added structured issue templates for bugs, features, integrations, model compatibility, and backend problems.
- Added a pull-request template with the project verification checklist.

## Compatibility

- No intentional breaking API or configuration changes.
- Existing `config.toml`, canonical `models.toml`, usage data, conformance history, and model files remain compatible.
- Docker artifacts have been removed. Docker was not a supported deployment path; use the documented Linux/systemd installer, a source build on macOS, or WSL2 on Windows.

## Install

### Prebuilt binary

```bash
curl -fsSL -o gguf-switchboard \
  https://github.com/pradeepgudipati/gguf-switchboard/releases/download/v0.1.8/gguf-switchboard-linux-amd64
chmod +x gguf-switchboard
```

See **Assets** for Linux and macOS builds plus `checksums.txt`.

### Upgrade from v0.1.7

```bash
cd gguf-switchboard
git checkout main && git pull
./deploy.sh
```

Existing runtime configuration and model registries are preserved.
